# 🧹 DataCleanerApp

**DataCleanerApp** es una aplicación desarrollada en Python que permite cargar bases de datos en formato `.csv` o `.xlsx` para visualizar, limpiar y modificar su contenido de forma sencilla e intuitiva.

## 🚀 Características

- 📂 Carga de archivos `.csv` y `.xlsx`
- 👁️ Visualización de la tabla de datos
- 🔍 Identificación de:
  - Valores nulos
  - Registros duplicados (ignorando valores nulos)
- 🧽 Limpieza automática de:
  - Valores nulos
  - Registros duplicados
- ✅ Confirmación visual tras cada limpieza
- ✏️ Posibilidad de modificar valores directamente (en futuras versiones)
